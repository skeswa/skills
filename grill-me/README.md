# grill-me

Tells Claude to interview you relentlessly about a plan or design — one question at a time, walking down the decision tree and recommending an answer at each branch — until you've reached a shared understanding.

Use it when you want to stress-test a design before writing any code.

## Origin

Lifted verbatim from [Matt Pocock's `skills` repo](https://github.com/mattpocock/skills) — specifically [`skills/productivity/grill-me`](https://github.com/mattpocock/skills/tree/main/skills/productivity/grill-me). Matt's whole collection ("Skills for Real Engineers, straight from my .claude directory") is worth a browse.
